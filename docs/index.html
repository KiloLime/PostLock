Your shorts, previewed before they go live.

PostLock is an open-source publishing tool for short-form creators. It turns a narration script into platform-ready titles and captions, then delivers the finished video to your TikTok inbox — and private on YouTube — so you give every post a final look. Nothing goes public without you.

Platform copy

One script in, title + caption + hashtags out, tuned per platform with a clear, question-raising short-form style.

TikTok draft delivery

Official Content Posting API upload flow (post_mode: MEDIA_UPLOAD, video.upload scope) into your inbox. Tap Post in the app when you're ready.

YouTube private upload

Uploads as private via the Data API v3 — publish or schedule in Studio. Full metadata arrives with the video.

Self-hosted, open source

MIT-licensed on GitHub. Bring your own keys, keep your own data.

Quick start

pip install requests
cp .env.example .env          # add your DeepSeek + TikTok credentials
python postlock.py captions --script script.txt --out captions.json
python postlock.py tiktok-draft --video final.mp4 --captions captions.json --dry-run
python postlock.py tiktok-draft --video final.mp4 --captions captions.json
