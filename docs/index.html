Your shorts, previewed before they go live.

PostLock is an open-source publishing tool for short-form creators. It turns a narration script into platform-ready titles and captions, then delivers the finished video to your TikTok inbox — and private on YouTube — so you give every post a final look. Nothing goes public without you.

Features

Platform copy

One script in, title + caption + hashtags out, tuned per platform with a clear, question-raising short-form style.

TikTok draft delivery

Official Content Posting API upload flow (post_mode: MEDIA_UPLOAD, video.upload scope) into your inbox. Tap Post in the app when you're ready.

YouTube private upload

Uploads as private via the Data API v3 — publish or schedule in Studio. Full metadata arrives with the video.

Self-hosted, open source

MIT-licensed on GitHub. Bring your own keys, keep your own data. No accounts, no cloud service, no tracking.

How it works

Write your narration

PostLock reads your final narration script (FINAL_SCRIPT.txt in your project's assets/writing_lab/ folder, or any script you point it at).

Generate platform copy

DeepSeek (or any OpenAI-compatible endpoint) turns the script into a title, caption and hashtags for TikTok and YouTube Shorts.

Deliver to your inbox

PostLock uploads the finished MP4 through the official TikTok Content Posting API as a draft — it lands in your TikTok inbox for review, never published automatically.

You tap Post

Open the TikTok app, give the draft a final look, and publish it yourself. Full control, every time.

Getting started

Desktop app (GUI)

  1. Install Python 3.10+ and requests (pip install requests).
  2. Download the project from GitHub.
  3. Copy .env.example to .env and add your DeepSeek API key and TikTok client key/secret.
  4. Run python postlock_gui.py, pick a finished video, and press Deliver to TikTok inbox. The app finds the script, generates captions, connects your TikTok account once via OAuth, and uploads.

Command line (CLI)

pip install requests
cp .env.example .env          # add your DeepSeek + TikTok credentials
python postlock.py captions --script script.txt --out captions.json
python postlock.py tiktok-draft --video final.mp4 --captions captions.json --dry-run
python postlock.py tiktok-draft --video final.mp4 --captions captions.json

The TikTok flow uses the official Content Posting API — Upload draft to TikTok endpoint (/v2/post/publish/inbox/video/init/). Your access token comes from the standard TikTok OAuth flow; PostLock never sees your TikTok password.

Troubleshooting

  • Authorization fails or times out — re-run the app and press "Connect TikTok (re-authorize)". Check that your TikTok client key/secret in .env match the developer app.
  • Draft takes a while to appear — TikTok processes uploads asynchronously. PostLock polls the status API for up to 10 minutes and reports progress.
  • Access token expired — the app detects it and re-authorizes once automatically.

FAQ

Does PostLock post anything automatically?

No. Uploads use post_mode: MEDIA_UPLOAD — the video lands in your TikTok inbox as a draft. Nothing is published until you tap Post in the TikTok app.

Is it free?

The software is free, open source (MIT). You only pay for the APIs you bring: your DeepSeek key and your TikTok/YouTube developer credentials.

Where are my API keys and tokens stored?

Only in the local .env file on your machine. PostLock runs a one-time OAuth consent in your browser and never sees your TikTok password.

Do I need to be technical to use it?

The GUI is a one-button flow: pick a video, connect TikTok once, and deliver. The CLI offers the same flow with more control.

Which TikTok scopes does it use?

user.info.basic (identify the connected creator) and video.upload (upload as draft to the creator's inbox). Direct posting is intentionally not enabled — you stay in control.

Does it work with YouTube Shorts?

Yes — captions are generated per platform, and the same video can be uploaded as private on YouTube via the Data API v3.
